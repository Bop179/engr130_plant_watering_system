ENGR 130 Project 3

## Problem

54% of plant owners claim overwatering as their largest unintentional plant killer; as well, 30% name improper light levels as their biggest issue. 

## Solution

An automatic/assistive plant care system that has an automatic watering system that can be remote controlled from a phone
